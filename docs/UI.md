# UI Direction — AeroChrono

## Personality
Premium historical aviation, not generic SaaS.

Visual references:
- classic airline timetables
- boarding passes
- airport split-flap boards
- route maps
- archival travel graphics
- modern premium travel apps

## Base palette direction
- very dark navy
- black
- warm white
- amber/gold accent
- muted aviation gray

Do not hardcode a final palette until UI tokens are defined.

## Mobile-first navigation
Bottom navigation:
- Home
- Explore
- Hangar
- Logbook
- Profile

## Core UI components
- TimelinePicker
- HistoricalRouteCard
- AirlineCard
- AircraftCard
- AirportCard
- EraBadge
- ConfidenceBadge
- SourceBadge
- FavoriteButton
- LoadingSkeleton
- EmptyState
- ErrorState

## Key experiences
### Home
"Para qual época você quer voar?"
Timeline + Surprise Me + exploration entry points.

### Historical route card
Must show:
- airline
- era/year
- aircraft
- flight number when known
- origin/destination
- confidence
- source access

### Transparency
Demo/unverified data must look visibly different from verified data.

## UX principle
Users should feel that selecting a year changes the aviation world around them.
